# MELD Toolbox · Web 0.9.5

A free community tool for managing MELD Studio sessions in your browser.

**[Open MELD Toolbox](https://snuggiettv.github.io/meld-toolbox/)**

## Get started
In MELD Studio, choose **File → Export Session** and save the `.json` file. Open the website and choose the tool you need.

| Tool | What it does |
| --- | --- |
| Quick Backup | Save an exact copy of your session JSON. |
| Import & Merge | Copy scenes from one exported session into another. |
| Export Scenes | Save selected scenes and the other scenes they need. |
| Full Backup & Portable | Include local media in a ZIP, or restore a ZIP made on the site. |

Import the resulting session JSON into MELD Studio. For media packages, follow the restore instructions to update file paths before importing.

## Privacy and limits
All file processing happens in your browser. Your files are not uploaded. Review private URLs before sharing exports. Session JSONs are limited to 50 MB, media files to 256 MB each, and packages to 1 GB total. For larger collections, create smaller packages by selecting fewer scenes. Remote assets, fonts, external scripts and hardware setup are not bundled.
