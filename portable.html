Prepare a backup for MELD

Moving a backup to a new folder or another computer? Prepare the original ZIP here before importing it into MELD.

Why this step is needed

MELD needs the full file paths of your images, videos and other local media. Extracting a backup by itself does not update those paths. Toolbox creates a new ZIP with a session.json that points to the folder you choose.

This does not extract files to your computer. You must download the prepared ZIP and extract it yourself.

Example: If you will extract your files into C:\Streaming\MELD Backup, enter that exact path below. Choose a new, empty folder. You can create it in File Explorer first. The browser cannot automatically detect its full path.

After downloading — do these steps yourself:
  1. In File Explorer, open your downloaded Restored-…zip and choose Extract All.
  2. Extract directly into the exact folder you entered above (no extra nested folder). The folder should contain session.json.
  3. If manual media copies are listed, copy those files to the exact locations shown.
  4. Use Verify extracted folder below, then import the extracted session.json into MELD Studio.

If you change the extraction location, prepare the original ZIP again using the new path.

Verify extracted folder before importing

After extraction and any manual copying, select the folder containing session.json and verification.json. Confirm the actual full folder path below. This checks included media by checksum and manual media by presence and size (when known). It cannot confirm manual file contents or the actual absolute folder path.

What is not copied automatically

Remote assets, browser sources and device settings stay as references only. Text files are snapshots. External scripts, fonts and hardware setup are not included.

Package limits: 1 GiB total and 256 MiB per included file. ZIPs are not compressed. Large files can be copied manually. Browser memory or file-access problems can still stop creation. Only original backup ZIPs created by this site can be prepared for MELD here.
