Save a session together with its local media, or restore a package you already saved.

Before you start

In MELD Studio, go to File → Export Session and save the .json file. To create a ZIP, you also need access to your media folders. To restore one, just choose your saved ZIP.

Choose a ZIP created by this web edition. Then enter the exact full path of a new, empty folder where you plan to extract it. Toolbox updates the media paths to that location.

After download: extract the restored ZIP directly into the exact folder you entered. Do not create an extra nested folder. Then import the extracted session.json into MELD Studio.
What is not copied automatically

Remote assets, browser sources and device settings stay as references only. Text files are snapshots. External scripts, fonts and hardware setup are not included.

Package limits: 1 GB total and 256 MB per file. ZIPs are not compressed. If a full backup is too large, make smaller packages by selecting fewer scenes. Only ZIPs created by this website can be restored here.
