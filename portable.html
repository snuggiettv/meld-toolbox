What is not copied automatically

Remote assets, browser sources and device settings stay as references only. Text files are snapshots. External scripts, fonts and hardware setup are not included.

Package limits: 1 GiB total and 256 MiB per included file. ZIPs are not compressed. Large files can be copied manually. Browser memory or file-access problems can still stop creation. Only original ZIPs created by this site can be restored here.
