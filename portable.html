Before you start

In MELD Studio, go to File → Export Session and save the .json file. You will also need access to the folders containing your media.

1. Choose your session

2. Find your media

Choose one or more folders where you keep your media. Toolbox matches the folder and file names from your session. Review all matches; if a match is missing or wrong, choose the correct file yourself.

Restore a web media package

Choose a ZIP created by this web edition. Enter the exact full path of a new, empty folder where you will extract the restored ZIP. Toolbox will update the media paths to that location.

After downloading: Extract the contents of the restored ZIP directly into the exact folder you entered. Do not create an extra nested folder. Import the extracted session.json into MELD Studio.

Limits

Up to 1 GB per package and 256 MB per file. ZIPs are not compressed. Desktop-created ZIPs are not supported by web restore. Remote assets, browser sources and device settings are retained as references only. Text files are snapshots; external scripts are not included.

Community tool, not an official MELD product. All processing happens on your device. Check your output before sharing.
