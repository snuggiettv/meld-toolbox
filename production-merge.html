Import & Merge

Copy scenes into another session. Neither original file is changed.

Before you start

In MELD Studio, use File → Export Session to save both sessions as separate .json files.

Step 1 · Choose the two session files

You can merge Main-only and dual-canvas sessions. The output keeps the destination canvas setup. Choose which layouts to transfer below.

Import FROM

The session with the scenes you want to copy.

Import INTO

The session you want to add scenes to.

Step 2 · Choose scenes and canvases

Select Main, Portrait or both. Toolbox includes any layouts required by Duplicators. For an existing scene, choose how to handle the selected layouts.

How canvas importing works

Main → Dual

New scenes get an empty Portrait layout. Merge and Overwrite keep an existing Portrait unchanged.

Dual → Main

Only Main is copied. If a Duplicator needs a Portrait layout, the import is blocked.

Dual → Dual

Choose either or both layouts per scene. Required layouts may be added. New counterparts are blank.

Keep BothMake a separate scene with selected layouts.
MergeAdd layers to the selected layouts.
OverwriteReplace only the selected layouts.
SkipKeep the existing scene unchanged.
Not sure? Keep Both is the default. It keeps the existing scene and creates a separate copy.
