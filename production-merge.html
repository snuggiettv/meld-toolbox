Import & Merge

Copy scenes into another session. Neither original file is changed.

Before you start

In MELD Studio, use File → Export Session to save both sessions as separate .json files.

Step 2 · Choose the scenes to copy

Toolbox also includes any other scenes your selected scenes need. If a scene name already exists, pick what should happen.

Keep BothMake a separate scene copy.
MergeAdd different layers to the existing scene.
OverwriteReplace the existing scene contents.
SkipKeep the existing scene unchanged.
Not sure? Keep Both is the default. It keeps the existing scene and creates a separate copy.
